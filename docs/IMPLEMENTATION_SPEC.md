# 小蜗桌宠技术规格与实现契约

版本 1.0，2026-11-22。基于 [产品规格](../SPEC.md) 与 [架构设计](TECHNICAL_DESIGN.md)。用户已授权按本文并行开发与测试。本文将已认可架构转成模块接口、数据约束、失败处理和验收责任；不改变产品目标。

## 1 技术与交付

Electron、TypeScript strict、React、electron-vite、electron-builder；Live2D采用官方Web SDK与独立适配器。依赖精确版本和依赖树由 package.json、package-lock.json 锁定。交付源码、可运行开发版本、当前环境可构建的安装制品、测试方案、实测报告及平台验收缺口。Windows/macOS以目标操作系统真实验收为准，Linux虚拟显示测试只能证明共享逻辑和可执行流程。

## 2 模块和所有权

| 路径 | 职责 | 本轮负责人 |
| --- | --- | --- |
| src/contracts/types.ts | IPC与状态类型，所有模块共同遵守 | 主agent |
| src/core | 编译预设、阶段查询、纯逻辑校验 | 开发agent |
| src/main、src/preload | 系统窗口、会话、保存、IPC | 开发agent |
| src/renderer，不含live2d | React界面、夜雨、声音、交互 | 主agent |
| src/renderer/live2d、resources/character | 模型检索、验证、官方SDK适配 | 角色agent |
| tests、测试配置、测试文档 | 独立测试设计、执行和缺陷报告 | 测试agent |
| package.json、锁文件、构建配置 | 单写者，统一依赖和构建 | 主agent |

业务契约变更先报告主agent，再同步其他agent；不同时修改同一模块。测试先复现并报告，开发修复根因；测试不通过放宽断言或改预期掩盖失败。模型和系统平台问题单独派回对应负责人，不让UI补丁绕开根因。任务达到完成条件或有明确外部阻塞时结束该agent，必要时复用现有agent处理回归。

本轮采用三个子 agent，主 agent 负责界面、契约和集成：

- 开发：gpt-6.2-astra，high。先完成计时、系统和存储；模块通过后转为拆分控制页面，修复窗口导航与注销保存。
- 角色：gpt-6.2-sol，high。先检索模型并验证官方 Cubism；确认没有可用角色文件后保留明确缺口，转为独立审查交互、演出和资源边界。发现问题由主 agent 或开发 agent 修复后独立复验。
- 测试：gpt-6.2-sol，high。独立维护测试方案与断言，负责故障注入、实际 Electron、多维性能和 40 分钟真实时间验证；最后汇总证据与未验收事项。

开发和角色审查在各自交付通过回归后结束；测试保持运行至长测和报告完成。遇到失败先区分应用缺陷、测试时序或宿主限制，再调整对应负责人：应用缺陷修根因；测试竞争改为观察确定事件；工具进程时限改为后台执行，不放宽产品判定。正式角色文件与双平台设备缺失保留为交付缺口，不让其他 agent 宣称替代验证。

## 3 共享契约

唯一接口定义见 [types.ts](../src/contracts/types.ts)。窗口只调用 `window.nightreign`，包含获取快照、提交命令、预览时间线、订阅状态及演出。preload不暴露Node或通用IPC。控制窗已存在时，主进程聚焦该窗口并发送受限页面导航通知（prepare、settings、result）。preload 转交给界面已有的页面切换逻辑，重复打开当前页面保留草稿，实际离开未保存的节奏页时显示确认。

快照包含会话、设置、预设、窗口可见性及错误。Session保存出击时编译后的时间线，设置和预设后续修改不影响当前局。阶段对象包含稳定id、种类、所属天、起止毫秒。阶段起点包含、终点不包含，结束时remaining归零。

命令分为会话、设置预设、窗口操作三组。会话ID和阶段ID用于拒绝旧窗口或过期点击；设置采用expectedRevision检测冲突。主进程校验发送窗口、数据类型、数值范围、命令状态与未知字段。会话命令在串行队列中处理；在执行前先更新到当前有效时间。

演出事件与快照分离。事件有唯一ID用于客户端去重；重连只恢复快照，不重放全部事件。只有主进程可以进入下一阶段或结算成功；动画回调不能推进时间。普通快照每250毫秒推送，隐藏窗口也不改变计时。

## 4 核心算法与状态

`compileTimeline(preset): Timeline`：原作模式白天固定为270、180、210、180秒，插入三场战斗；适配模式保留1680秒白天，剩余按3:4:5且各至少60秒分配，最大余数取整；自定义输入11段整数秒。所有阶段至少1秒，总时长不超过10800秒，适配模式总时长至少1860秒。

`getPhase(timeline, elapsedMs): Phase | null`：有效时间到总时长后返回null，不把最后一场重复显示为未完成。剩余时间为max(0, endMs-elapsedMs)，界面显示秒数向上取整。

会话状态idle通过session=null表达，其余running、paused、completed显式保存。运行有效时间来自单调时钟锚点；暂停结算累计时间并清锚点；恢复重建锚点。修改系统日期不影响计时。重复出击需拒绝。绝招通过独立演出事件触发，可在任何会话状态下重复施放，不写课程进度。

完成和主动放弃在磁盘确认后再展示结果，避免重启恢复已结束的局。未完成会话启动后一律paused并提供继续／放弃。退出期间不计时。睡眠总是暂停；锁屏按设置。恢复不补算睡眠时间。

## 5 存储和失败

数据位于userData，采用带schemaVersion的JSON与同目录临时写入、原子替换、上一份备份；单写者串行处理。生产正常运行每2秒检查点，重要状态立即保存。写入持续超过5秒未成功则暂停并提示故障。损坏文件保留，优先读有效备份；设置损坏可以恢复默认，会话损坏不得捏造进度。

快捷键、开机启动及窗口设置须操作成功后确认。Linux不支持的开机启动操作要明确返回不支持，而非保存为成功。任何IPC失败转换为用户能理解的消息；界面保留上一次有效快照并允许重试。

测试通过独立用户数据目录运行。生产包不能开放任意设置时间、任意路径读写或执行代码的测试IPC。单元测试注入时钟，桌面测试用合法自定义短局而非生产后门。

## 6 窗口与角色

桌宠为透明、无边框、非焦点窗口；控制窗单独可聚焦，关闭不停止渡夜。显式开启鼠标穿透覆盖模型命中；关闭后通过模型区域和时钟表冠恢复交互。拖动与点击需阈值区分，位置锁定仅禁止移动。托盘始终提供显示小蜗、关闭穿透、设置、退出与重置位置。恢复坐标限制在可用屏幕范围。

角色必须是复仇者小蜗。真实模型文件、作者、来源、使用条件、动作清单记录在CHARACTER_ASSETS.md。只找到截图、MMD或通用Live2D样例不算完成。若模型缺失，应用展示清晰的资源未就绪状态并保留其他功能，不用别的角色冒充；该情况必须列入交付阻塞项。

Live2DAdapter独立管理load/dispose、rAF、尺寸、DPR、WebGL恢复与hitTest。动作语义为 idle、touch、battle、battle2、nightlord、ultimate 与 victory。待机与探索时，渲染器把鼠标在画布中的位置映射到目光、侧倾与俯仰。每帧在动作参数保存后叠加跟随，以便移开鼠标时恢复当前编排。双击由系统点击计数识别，两次都需命中人物。特效网格不参与命中判定。夜雨用单独Canvas2D，不截获输入。SDK Framework、Core与模型版本作为兼容组合核验；资源随包本地加载。

## 7 界面与设置

控制窗口使用深夜蓝黑、旧金、雾白和少量冷蓝；环形夜雨与时间线是主要识别元素。准备页突出「出击」、当前总时长、分段时间线和小蜗资源状态。用户界面不展示IPC、进程、SDK等实现名词。

四页设置分别为渡夜节奏、小蜗与桌面、声音与演出、操作与运行。时间设置草稿保存后用于下次出击，完整显示分段预览；其他设置即时生效。表单提供单位、范围和错误，全部输入有标签、焦点状态及键盘操作。总静音和安静模式采用覆盖层，不破坏底层音量偏好。

结算横幅固定为NIGHTLORD SLAIN。首领战斗自动结束，无互动也成功；提前放弃无胜利。控制窗口显示摘要与再次出击，不自动开下一局。

## 8 验证和完成标准

测试agent独立编写TEST_PLAN与TEST_REPORT：核心边界、故障恢复、IPC、配置持久化、桌面交互、模型真实性、视觉、键盘易用性、资源占用、长期计时与安装。自动化使用Vitest与Playwright Electron；当前环境采用Xvfb运行实际Electron。截图须检查真实渲染，不仅检查DOM。

必须至少验证默认2400秒、全部阶段节点、31/40/45分钟适配、非法输入、旧命令、全状态绝招与连续双击、恢复、磁盘损坏／失败、界面设置与短局结算。性能报告包含设备和进程测量口径，不能从开发环境软件渲染结果推出目标电脑GPU功耗。真实40分钟测试与虚拟时钟测试分别记录。

通过条件：类型检查、构建、单元/集成测试、实际Electron基本流程均通过；发现的阻塞缺陷修复并回归。真实小蜗和目标系统未验证时，不得标为最终产品全部完成。源码和文档可独立交付，但需要明确剩余依赖，不能用“测试全通过”掩盖缺失角色。
