# 桌宠独立代码审阅

2026-11-22 · 0.1.0 独立审阅。复现使用 Linux Electron 和临时用户目录，通过 Playwright 观察窗口、渲染结果和 IPC。鼠标测试覆盖了从渲染器命中到主进程穿透设置的调用。Windows 和 macOS 的真实桌面事件仍需对应平台验证。

## 已复现的问题

| 场景 | 复现和结果 | 状态 |
| --- | --- | --- |
| 透明立绘截获鼠标 | 原构建中，立绘 PNG 像素 `(3,3)` 的 alpha 为 `0`，其画布位置仍落入整个 `<img>` 的点击区。 | 修改后复测通过。移动到透明角时进入穿透，移动到角色实心区域时恢复交互。[命中逻辑](../src/renderer/pet/presentation.ts) |
| 拖动过程中启用穿透 | 按下角色再移动，指针捕获将事件目标变成 `pet-scene`。原构建在 `buttons=1` 时调用 `setIgnoreMouseEvents(true, { forward: true })`。 | 修改后复测通过。按住并移动期间没有额外的穿透切换。[拖动逻辑](../src/renderer/pet/PetWindow.tsx) |
| 缩圈间隙光环变大 | 短时间线中，首缩圈末段的缩放约 `0.765`，圈内探索跳到 `1`，次缩圈又从约 `0.989` 开始。 | 修改后复测通过。首缩圈末段约 `0.816`，圈内探索保持 `0.76`，次缩圈从 `0.76` 继续缩小。[光环规则](../src/renderer/pet/presentation.ts) |
| 重新打开同一设置页触发草稿警告 | 在「渡夜节奏」修改预设名称，桌宠窗口请求打开 `settings`。控制窗口已经在该页，主进程仍重新加载页面，并弹出「继续编辑／放弃修改」。 | 修改后复测通过。重新打开已出现的同一设置页后，原草稿保留且未出现原生对话框。[控制窗口](../src/main/windows.ts) |
| 缺少角色时具体错误只存在于提示属性 | 使用当前缺失清单启动后，桌宠可见文字只有「立绘预览 · Live2D 待接入」，具体原因放在按钮 `title`。点击该按钮打开控制面板，通用提示仍无法区分缺 `.moc3`、贴图路径错误或 WebGL 初始化失败。 | 修改后复测通过。点击「查看模型加载详情」能读到当前缺失清单给出的完整原因，详情可关闭，随后可重试加载。[模型回退界面](../src/renderer/pet/PetWindow.tsx) · [Electron 回归](../tests/desktop/desktop.spec.ts) |
| 演出预览没有雨 | 待命状态下设置强演出，点击「预览」。原构建出现「夜雨将至」和声音，夜雨画布像素 alpha 总和为 `0`。 | 修改后复测通过。强演出预览出现雨，计时会话仍为空，切到低强度后画布清空。[演出切换](../src/renderer/pet/PetWindow.tsx) |
| 正在播放的声音未响应音量 | 从 100% 音效开始预览，提示音启动后把滑杆调为 0。原构建的两个振荡器只保留原计划的 `0.9s` 与 `1.04s` 停止调用。增益未改变。 | 修改后复测通过。音量归零时，两个振荡器收到立即停止调用，主增益目标同步降为零。[音效音量](../src/renderer/pet/AudioDirector.ts) |
| 减少动态时夜雨仍播放 | 启用 `prefers-reduced-motion: reduce`，进入缩圈。原构建两帧的像素 alpha 总和从 `25086` 变成 `25193`。同一设置已用于模型和 CSS。 | 修改后复测通过。缩圈保留静态雨纹，间隔 250 毫秒的两帧像素一致。[夜雨与减少动态](../src/renderer/pet/PetWindow.tsx) |
| 启动警告的关闭按钮无效 | 临时目录放入损坏的 `preferences.json`。启动后显示「preferences 无法读取，原文件已保留。」点击「关闭错误提示」后仍显示同一条警告。 | 修改后复测通过。关闭提示后告警消失，后续设置更新未重新显示同一条告警。[控制面板提示](../src/renderer/App.tsx) · [状态与警告](../src/renderer/useDesktop.ts) |

在实际缩圈时暂停，观察到尚在播放的音符立即停止，夜雨画布相隔 350 毫秒的两帧一致。

## 资源与权限抽查

- `app://` 模型清单在 Electron 内返回 `200`，包含编码分隔符的越目录路径返回 `400`。代码在解码后校验父目录段，并使用真实路径约束资源目录。[本地资源协议](../src/main/resources.ts)
- 桌宠尝试打开弹窗时被拒绝，尝试导航至资源 URL 后仍在应用入口。桌宠窗口直接请求出击命令时被拒绝。应用窗口启用上下文隔离和沙箱，主进程核对主框架和窗口权限。[窗口约束](../src/main/windows.ts) · [IPC 权限](../src/main/ipc.ts) · [预加载桥](../src/preload/index.ts)
- 当前应用资源清单标记为 `missing`，桌宠和控制面板均将展示素材标为同人立绘预览。这个构建的复仇者 Live2D 交付仍待补齐。[角色资源记录](CHARACTER_ASSETS.md)
