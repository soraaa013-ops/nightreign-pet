# 0.3.0 桌宠体验验收

## 拖动

复现路径是在 125% 系统缩放下，反复将窗口向两个方向移动一个逻辑像素。旧版将系统取整后的窗口尺寸用于下次移动，宽度从 320 增长到 423。现在由桌宠设置决定宽高，拖动只累计逻辑坐标，抬起鼠标后再将桌宠收回目标屏幕的工作区。

125% 和 150% 的 Electron 回归都包含一百次往返移动、实际指针手势、画布尺寸对比及屏幕边缘释放。两档往返前后的原生位置、宽高和画布纹理大小一致。[窗口回归测试](../../tests/desktop/pet-drag.spec.ts)

## 计时

真实短局依次走过两天探索、四次缩圈、两夜首领和夜王。桌宠和控制面板读取同一份计时快照。缩圈中途暂停后，在 50%、100%、200% 三种桌宠尺寸都能读到冻结的阶段与整局进度；完成时显示实际用时。默认 40 分钟时间线沿用原作节奏预设。[时间线规格](../../SPEC.md) · [桌宠和面板回归](../../tests/desktop/hud.spec.ts)

## 角色

官方 Cubism Core 成功读取成品模型。九个网格共用一张图集，十一个参数驱动眼睑、琴和手臂、重心、屈膝、步伐及灵体。独立模型包内的可编辑工程可回读 22 个动画场景。逐一取 22 段动作的六个时刻，在 320 像素宽的实际 WebGL 画布上检查，132 个采样画面均完整入框。两段绝招和夜王的终奏会显现灵体。[模型与动作源文件](../../scripts/character-rig/) · [默认尺寸战斗截图](./revenant-desktop.png)

24.22 秒动作预览展示七个场景。按固定时间步调用与应用相同的 Cubism 渲染器，编码得到 361 帧；默认尺寸截图直接采自实时运行的桌宠窗口。图片使用 ImageGen 原稿，网格、变形与动作曲线保存在仓库中。[分层原稿](../../art/revenant/) · [动作预览](./revenant-live2d.webp)

## 资源占用

Linux x64 发行包在 2 vCPU、Xvfb、Vulkan SwiftShader 环境中运行 6.5 分钟。每种状态预热 30 秒，再取 60 个样本。表中的 CPU 和 RSS 是 Electron 各进程的报告值之和。运行时同机有其他渲染任务，这次数据用于记录该环境的实际开销。[采样方法](../../tests/desktop/performance.spec.ts)

| 状态 | 平均 CPU | 平均 RSS |
| --- | ---: | ---: |
| 待机 | 7.42% | 316.51 MiB |
| 探索 | 6.73% | 361.79 MiB |
| 强缩圈演出 | 11.29% | 323.43 MiB |
| 隐藏桌宠 | 7.33% | 302.89 MiB |

隐藏时模型绘制会停止，Electron 进程仍有开销。Windows 笔记本的功耗和硬件 GPU 帧率未实测。

## 发行包

Windows Server 2022 原生任务验证了 125% 和 150% 拖动、完整 HUD 流程，随后解压便携 ZIP 并启动其中的 EXE。macOS 任务挂载 DMG，启动其中的 Apple 芯片应用。两者都实际读取新模型、完成 11 阶段短局和一次胜利结算，并验证首次许可选择与重启。Linux x64 发行程序也在 Xvfb 中走通同一流程。各平台的测试报告和产物校验值见构建记录。[原生测试与构建产物](https://github.com/soraaa013-ops/nightreign-pet/actions/runs/44976015920)
