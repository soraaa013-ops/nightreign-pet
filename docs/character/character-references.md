# 小蜗的造型与模型来源

这次制作采用原创同人插画与绑定。中、英、日文补查中仍未找到可以核验模型文件及分发许可的完整复仇者 Live2D。最接近的两个作者发布物分别是 Toon Boom Harmony 25 的 `.tpl` 工程和 VTube Studio 用的前后两张头纱 PNG。[Harmony 模型作者页](https://reanuimatai.gumroad.com/l/cwazw) · [头纱作者页](https://ko-fi.com/s/686d6bf601) · [此前各平台的检索记录](../CHARACTER_ASSETS.md)

当前画稿以官方图中的银发花冠、浅蓝披肩、象牙白衣袖和浅色里拉琴为造型参考。桌宠保留了身侧的长发轮廓，琴框和手臂之间留有空隙。官方指南将里拉琴列为她召唤家人的乐器。[万代南梦宫角色图](https://static.bandainamcoent.eu/high/elden-ring/elden-ring-nightreign/04-character-gallery/01-thumbnail/V2/revenant-thumbnail-V2.png) · [官方角色技能](https://www.bandainamcoent.com/games/nightreign/gameplay-guide#nightreign-cnt-revenant)
