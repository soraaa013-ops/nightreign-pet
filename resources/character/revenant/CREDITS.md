# 小蜗 · 复仇者

《艾尔登法环：黑夜君临》复仇者的项目自制同人桌宠，2026-11-22。造型参考了万代南梦宫公开的角色图。分层画稿使用 ImageGen 制作，网格、动作曲线和绑定由本项目制作。官方角色图仅用于造型参考。原作角色与相关标识的权利归各自权利人。

在支持相应 Cubism 版本的播放器中打开 `revenant.model3.json`，并保留同目录的 `.moc3`、贴图子目录和五个动作文件。桌宠读取 `manifest.json`，把 `Idle`、`Touch`、`Battle`、`Ultimate`、`Victory` 分别映射为待机、轻触、战斗、绝招和胜利。需要编辑模型或修改动作时，使用项目提供的 `.cmo3` 和 `.can3` 工程。
