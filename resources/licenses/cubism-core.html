Cubism Core 使用条款

小蜗使用 Live2D Cubism Core 播放角色动画。这份约定仅适用于随应用提供的 Cubism Core 代码。

  • 按 Live2D 许可授权的方式使用 Core，并保留其版权标识和许可声明。
  • 除许可或适用法律允许外，请勿修改、反向工程、反编译或反汇编 Core，也请勿单独分发、转授权或出售它。
  • 如果你依照许可再分发包含 Core 的应用，请保留 Core 原样，并要求接收者同意同等保护条款。

选择「同意并进入」，即表示你同意遵守 Live2D 许可中适用于保护该可再分发代码的条款。
